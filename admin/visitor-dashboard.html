Send SMS/WhatsApp when a new session begins (not per page view)
Notify Number
Your mobile number to receive alerts (with country code)
Setup required: SMS alerts use Twilio. Add these to your .env file:
TWILIO_ACCOUNT_SID=ACxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxx
TWILIO_FROM=+1xxxxxxxxxx  (your Twilio number)
Then run npm install twilio and restart the server.

For India: WhatsApp via Twilio works best. Use TWILIO_FROM=whatsapp:+14155238886 for the sandbox, or your registered WhatsApp Business number.
SVIE Visitor Dashboard collects IP address and, where granted, precise device location, in addition to country, city, browser, and device. Visitor consent is obtained before any data is recorded. No cookies. This level of data collection falls under GDPR (EU Regulation 2016/679) and DPDPA 2023 (India) as personal data — have counsel confirm your privacy policy and lawful basis before relying on a compliance claim.
