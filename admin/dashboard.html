Visitor Notifications — 100% Free
Get an instant alert when a new visitor arrives. Choose Signal, Email, or both. No paid service needed.
Signal (Private & End-to-End Encrypted)
Alerts delivered over Signal — the most private messenger. Self-hosted via signal-cli-rest-api, so you own all the data. Supports multiple recipients.
⚠ Requires Docker on your server. Signal has no cloud API, so alerts only send when a signal-cli-rest-api container is running 24/7 on your host. This works on a VPS or any host that allows Docker / long-running containers — but not on basic shared hosting. If your plan can't run Docker, leave Signal off and use Email alerts below instead.
Signal API URL
Sender Number (registered with Signal)
Recipient Number(s) — comma-separated
Setup (one time):
1. On your server, start signal-cli-rest-api (Docker):
docker run -d --name signal-api -p 8080:8080 -v $HOME/.local/share/signal-cli:/home/.local/share/signal-cli -e MODE=native bbernhard/signal-cli-rest-api
2. Register your sender number and verify the SMS code (see the API's /v1/register docs at http://localhost:8080/v1/about).
3. Enter the API URL, sender number, and recipient number(s) above → Save → Test.
Email Alerts (Gmail / any SMTP — Free)
Send alerts to any email. Uses Gmail's free SMTP. Requires npm install nodemailer once.
Gmail address (sender)
Gmail App Password
Alert delivered to
Gmail setup: Go to myaccount.google.com → Security → 2-Step Verification → App passwords → create an app password → paste it above. In terminal: npm install nodemailer
