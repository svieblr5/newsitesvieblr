What is SVIE Visitor Dashboard?

A built-in website analytics system — similar to Twipla or Google Analytics — but hosted entirely on your own server, with SMS alerts to your phone and zero third-party data sharing.

🗺️
World Map
Interactive Leaflet.js map showing visitor locations with circles sized by visit count. Click any marker for city details.
📊
Live Charts
Visitor trend line, device breakdown (Desktop/Mobile/Tablet), and traffic source analysis (Direct/Search/Social/Referral).
📱
SMS Alerts
Receive a WhatsApp or SMS notification on +91 9513961740 whenever a new visitor lands on the website.
🏆
Ranked Lists
Top countries, top cities (state + country), top pages visited, and browser breakdown — all with visual bars.
📋
Visitor Table
Paginated table of all visit records: time (IST), city with country flag, page, device badge, browser, and session type.
⬇️
CSV Export
Download all visitor records as a CSV file for external analysis in Excel, Google Sheets, or any BI tool.
⏱️
Time Filters
Filter all charts and data by: 7 Days, 30 Days, 90 Days, 1 Year, or All Time. Data updates live.
🔒
Privacy First
Consent banner before any tracking. Full IPs never stored. No cookies. Compliant with GDPR and India's DPDPA 2023.
🔗
CMS Integrated
Accessible from the SVIE CMS sidebar under "Analytics". Protected by the same admin login. Data stored in data/visitors.json.

SMS / WhatsApp Alert Setup

Alerts are sent via Twilio. WhatsApp is recommended for Indian numbers — it works instantly with no DLT registration required.

1

Create a free Twilio account

Visit console.twilio.com and sign up. Your Account SID and Auth Token are on the dashboard homepage.

2

Install Twilio in the project

Run in your project folder:

npm install twilio
3

Configure your .env file

Create a .env file (copy from .env.example) and fill in:

# Twilio credentials from console.twilio.com
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# WhatsApp (recommended for India — no DLT registration needed):
# Sandbox testing (free):
TWILIO_FROM=whatsapp:+14155238886

# OR for standard SMS (requires DLT registration for India):
# TWILIO_FROM=+1xxxxxxxxxx

# Your mobile number to receive alerts:
NOTIFY_PHONE=+919513961740
4

For WhatsApp Sandbox: Send a join message

WhatsApp +91 9513961740 must send the message join <sandbox-word> to +1 415 523 8886 once. The sandbox word is shown in your Twilio console under Messaging → WhatsApp Sandbox.

5

Enable alerts from the dashboard

Restart the server, open the Visitor Dashboard, scroll to SMS / WhatsApp Notifications, toggle Enable Visitor Alerts ON, and save.

Sample alert message you will receive:

Legal Compliance

GDPR — EU Regulation 2016/679

General Data Protection Regulation

  • Explicit consent obtained before any tracking
  • IP addresses anonymised (last octet removed)
  • No cross-site tracking or fingerprinting
  • Data minimisation — only what's necessary
  • Right to erasure (admin can wipe all data)
  • Purpose limitation — analytics only
  • Data stored on-premises (your own server)
  • No transfer to third-party analytics companies
DPDPA 2023 — India

Digital Personal Data Protection Act

  • Free, specific, informed and unambiguous consent
  • Clear notice before data collection
  • Purpose stated: website analytics/performance
  • Consent can be declined (decline button provided)
  • No sensitive personal data collected
  • Right to erasure supported via admin panel
  • Data Principal informed via consent banner
  • Privacy Policy linked in consent banner
What makes this compliant: The consent banner appears before any tracking occurs. If the visitor declines, nothing is recorded. The consent choice is remembered in localStorage (not a cookie), so the banner only shows once. Visitors can clear their browser storage to reset consent.

API Endpoints Reference

MethodEndpointAuth?Description
POST /api/visitor-ping No (public) Called from frontend after consent. Records visit, geolocates IP, sends SMS if new session.
GET /api/visitor-stats Yes (admin) Aggregated analytics: KPIs, map points, charts data. Params: ?days=30
GET /api/visitors Yes (admin) Paginated raw visitor records. Params: ?days=30&page=1&limit=50
GET /api/visitor-export Yes (admin) Downloads visitor data as CSV file. Params: ?days=30
PATCH /api/visitor-settings Yes (admin) Toggle SMS alerts and update notify phone. Body: {smsEnabled, notifyPhone}
DELETE /api/visitors Yes (admin) Permanently delete all visitor records. Irreversible.

Troubleshooting

IssueSolution
No visitors appearingVisitors must click "Accept" on the consent banner. Check browser console for errors on /api/visitor-ping.
All locations show "Localhost"Normal when testing locally. Real IP geolocation only works on the live server (svie5.com).
Map doesn't loadEnsure internet connection (Leaflet loads from cdnjs.cloudflare.com). Check browser console for CSP errors.
SMS not sendingVerify .env has correct Twilio credentials. Run npm install twilio. Check server console for [Visitor SMS] errors.
WhatsApp not receivingThe notify number must have sent the Twilio sandbox join message first. Check Twilio console for message logs.
Dashboard shows "Session Expired"Log in to the CMS at /admin first. Sessions expire after 8 hours of inactivity.
CSV export emptyNo visitors have consented yet, or the selected time period has no data. Try "All Time" filter.
ip-api.com rate limitFree tier allows 45 requests/minute. Results are cached for 1 hour per IP. Upgrade to ip-api.com Pro if needed.
