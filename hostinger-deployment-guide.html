Section 3 — Upload Your Website Files

3.1 Method A — File Manager (Easiest, No Software Needed)

1 Open File Manager in hPanel

In hPanel, click on your website → Go to Files → File Manager.

You will see a folder called public_html. This is your website's root folder — everything visible online lives here.

2 Compress Your Project Files

On your computer, go to your svie-redesign folder on your Desktop.

Select ALL files and folders (Ctrl+A), then Right-click → Compress to ZIP file.

Name it svie-website.zip.

Exclude the node_modules folder from your ZIP. It is very large (hundreds of MBs) and will be regenerated on the server. Right-click → "Send to Compressed" → then delete node_modules from the zip if it got included.
3 Upload and Extract ZIP

In File Manager, navigate inside public_html and click Upload Files.

Upload your svie-website.zip file.

After upload completes, right-click the ZIP file → Extract → extract into public_html.

Your file structure should look like:

public_html/ ├── index.html ├── about.html ├── services.html ├── products.html ├── furniture.html ├── electronics.html ├── gallery.html ├── contact.html ├── styles.css ├── script.js ├── server.js ├── cms-loader.js ├── package.json ├── admin/ ├── data/ └── images/

3.2 Method B — FTP Upload (Recommended for Large Files)

1 Download FileZilla (Free FTP Client)

Download FileZilla from filezilla-project.org (free, trusted).

Install and open it.

2 Get FTP Credentials from hPanel

In hPanel → Files → FTP Accounts.

Note down the following credentials:

FieldWhere to Find ItExample
Host / FTP ServerShown in FTP Accounts pageftp.yourdomain.com
UsernameYour hPanel FTP usernameu123456789

PortDefault21
3 Connect and Upload via FileZilla

In FileZilla, fill in the Quickconnect bar at the top with Host, Username, Password, Port → click Quickconnect.

On the left side (your computer): navigate to your svie-redesign folder.

On the right side (server): navigate to /public_html.

Select all your files on the left (except node_modules) → drag and drop to the right panel.

Wait for upload to complete. This may take 5–15 minutes depending on image file sizes.

Section 4 — Configure the Node.js CMS on Hostinger

This is the most important section. Your server.js (the CMS backend) must be registered and started as a Node.js application in hPanel.

1 Open the Node.js Manager in hPanel

In hPanel → go to Advanced section → click Node.js.

If you do not see "Node.js" in hPanel, you may need to upgrade to the Business plan — go to Hosting Plans to upgrade.

2 Create a New Node.js Application

Click Create Application and fill in the following settings:

SettingValue to EnterExplanation
Node.js Version 18.x or 20.x (latest LTS) Latest stable version — compatible with Express 4
Application Mode Production Use Production for live website
Application Root /public_html Where your files are uploaded
Application URL yourdomain.com Your website's domain or subdomain
Application Startup File server.js Your main Node.js file

Click Create to save the application.

3 Install Node.js Dependencies (npm install)

After creating the application, hPanel will show a button to run commands. Click Run NPM Install or open the Terminal in hPanel:

In hPanel → Advanced → SSH Access (or Terminal), then run:

cd public_html npm install

This will install all dependencies listed in package.json:

  • express
  • multer
  • express-session
  • cors

Wait until you see "added X packages" — this confirms all packages are installed.

4 Change the Port Number in server.js
Required Change: Your server.js currently listens on port 3000. On Hostinger, Node.js apps must use the port provided by the environment variable process.env.PORT. You must update this line.

In hPanel File Manager, open public_html/server.js → Edit.

Find this line (line 8 in your file):

const PORT = 3000;

Replace it with:

const PORT = process.env.PORT || 3000;

Save the file. This ensures the app works both locally (port 3000) and on Hostinger's server.

5 Start the Node.js Application

Go back to hPanel → Advanced → Node.js.

Find your application in the list and click the Start (▶) button.

The status should change to "Running" (green indicator).

Success indicator: When the status shows "Running" in green, your Node.js CMS server is live and serving your website.
6 Verify the Application is Working

Open your browser and navigate to your domain (e.g., https://svie5.com).

Test the following URLs to confirm everything is working:

URLExpected Result
yourdomain.comSVIE Home page loads
yourdomain.com/adminCMS Admin login page loads
yourdomain.com/contact.htmlContact form works
yourdomain.com/gallery.htmlGallery loads correctly

Section 5 — Domain Setup (Point svie5.com to Hostinger)

If your domain (svie5.com) is registered with another provider (e.g., GoDaddy, Namecheap, current Wix), you need to point it to Hostinger.

5.1 Option A — Update Nameservers (Recommended)

1 Get Hostinger's Nameservers

In hPanel → Domains → Click on your domain → DNS / Nameservers.

Hostinger's nameservers are:

ns1.dns-parking.com ns2.dns-parking.com

Or the ones shown in your specific hPanel account.

2 Update Nameservers at Your Current Domain Registrar

Login to wherever you registered svie5.com (GoDaddy, Namecheap, etc.).

Go to Domain Settings → Nameservers → Switch to Custom Nameservers.

Replace existing nameservers with Hostinger's nameservers shown above.

Save the changes.

DNS Propagation Time: After changing nameservers, it takes 24–48 hours for the change to fully propagate worldwide. During this time, some visitors may see the old site. This is normal.

5.2 Option B — Point DNS Records Only (Faster)

1 Get Your Hostinger Server IP Address

In hPanel → Hosting → click on your hosting plan → Look for Server IP Address (e.g., 185.x.x.x).

Write this IP down — you will need it in the next step.

2 Update DNS A Records at Your Registrar

At your domain registrar, go to DNS Management and update:

Record TypeHost / NameValue / Points ToTTL
A Record@ (or blank)Your Hostinger Server IP3600
A RecordwwwYour Hostinger Server IP3600
CNAMEwwwyourdomain.com3600

Propagation via this method typically takes 1–4 hours.

Section 6 — Enable Free SSL Certificate

1 Install SSL in hPanel

In hPanel → Security → SSL Certificates.

You will see your domain listed. Click Install next to the Free (Let's Encrypt) option.

Hostinger will automatically generate and install the SSL certificate for your domain.

2 Enable Force HTTPS

After SSL is installed, in the same SSL page, toggle on "Force HTTPS".

This automatically redirects all http:// visitors to https:// — essential for security and Google ranking.

Section 7 — Set Up Automatic Backups

1 Enable Daily Backups (Business Plan Feature)

In hPanel → Files → Backups.

The Business plan includes daily automated backups. Enable this feature and keep at least 7 days of backup history.

This protects your CMS content data stored in data/content.json, data/enquiries.json, and your gallery images.

2 Download Manual Backup via SVIE Admin Panel

Your SVIE CMS admin panel has a built-in backup feature. Use it before and after any major changes:

Login to yourdomain.com/admin → Go to Settings → Click Download Backup.

This downloads a svie-backup-YYYY-MM-DD.json file containing all your content. Store this file safely on your computer or Google Drive.

Section 10 — Troubleshooting Common Issues

Problem Likely Cause Solution
Website shows "500 Internal Server Error" Node.js app crashed or not started Go to hPanel → Node.js → Restart the application. Check error logs.
Website shows blank/white page index.html not in public_html root Check File Manager — make sure index.html is directly inside public_html, not in a subfolder.
"Cannot find module" error npm install was not run Go to hPanel Terminal → cd public_html → npm install
Admin panel not loading (/admin returns 404) admin/ folder not uploaded, or Node.js not running Verify admin/ folder exists in public_html. Restart Node.js app.
Images not showing on website Images folder not uploaded or wrong path Ensure images/ folder was uploaded to public_html. Image paths in HTML are relative.
Contact form not saving enquiries data/ folder missing or not writable Check data/ folder exists in public_html. In hPanel File Manager, right-click data/ → Permissions → set to 755.
Domain still showing old Wix site DNS not propagated yet Wait 24–48 hours. Check propagation at dnschecker.org
SSL not working (http only) SSL not installed or Force HTTPS not enabled hPanel → Security → SSL Certificates → Install Let's Encrypt → Enable Force HTTPS
Node.js app keeps stopping App crashing due to unhandled error Check error logs in hPanel. The app may need PM2 process manager — contact Hostinger support to enable.
Slow page load speeds Large unoptimized images Compress images using squoosh.app before uploading. Enable Hostinger CDN in hPanel → Speed section.
